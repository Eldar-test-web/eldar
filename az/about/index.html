İlk maraqdan indiki istiqamətə.

Altı mərhələdən ibarət faktiki tərcümeyi-hal - robototexnika yarışları, proqramlaşdırma, mühəndis alətləri, elmi müsabiqələr, AI və kibertəhlükəsizlik - yalnız sənədli material əsasında.

Yalnız sənədli məlumat
  1. Erkən maraq

    Niyə hərəkət etdiyini görmək üçün sökmək.

    Sumqayıtda məktəb illərində formalaşan ümumi texniki maraq, 2020-ci ilə doğru sistemli robototexnika fəaliyyətinə keçid.

  2. Robototexnika

    Müsabiqə robototexnikası, 2020-dən.

    RoboCross Onlayn Çağırışı (Dünya 2-cisi, 2020), WRO Robot Virtual Oyunları finalçısı (2020), WRO Kanada 2020-X 5-ci yer, SUMracers ilə Misir beynəlxalq olimpiadası (5-ci, 2021), WRO Azərbaycan finalçısı (2024), AIRO 2-ci yer (2026).

  3. Proqramlaşdırma

    Scratch-dən Python və C++-a.

    V Beynəlxalq Scratch Yaradıcı Proqramlaşdırma Olimpiadasında Milli Seçim Finalçısı (2021); Bebras yarımfinal və Bebras ABŞ Şərəf siyahısı (2024-2025). Hazırkı iş dilləri: Python və C++.

  4. Mühəndislik

    Alətlər və hazırlıq.

    Dizayn və prototipləmə üçün Fusion 360, SolidWorks və FreeCAD təcrübəsi, standart proqram bilikləri ilə (MS Windows, MS Excel). SAF-2023 xilasedici çanta işi İnnovativ Sərgi kateqoriyasında qalib olub.

  5. AI / Kibertəhlükəsizlik

    Dar, tətbiqi tədris.

    Beynəlxalq Məktəblər AI Olimpiadası Şərəf siyahısı (2025) və Milli Yeniyetmə Kibertəhlükəsizlik Olimpiadası 2-ci yer (2025). Yalnız laboratoriya təcrübəsi; canlı sistem sınağı yoxdur.

  6. İndiki istiqamət

    Fərqlənmə ilə orta təhsil, irəliyə hazırlıq.

    Diqqət universitet hazırlığı, mühəndislik müsabiqələri və GitHub və qeydlər vasitəsilə paylaşılan sənədli layihə işinə yönəlib.
